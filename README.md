# Swadesh Vani (स्वदेश वाणी) - Media & News Portal

A modern, high-performance digital news portal built with React, Vite, Tailwind CSS, Express backend, and live real-time Convex Cloud database synchronization.

---

## 🚀 Quick Start (For Non-Developers & Developers)

### Option 1: Run Locally in 2 Steps

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start the Application**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173`.

---

## 🌐 Live Database & Backend

- **Convex Cloud Backend**: Automatically connected to live cloud sync.
- **Production Server**: Express server inside the `/server` directory for production hosting (cPanel, Node.js hosting, VPS).

To start the production server:
```bash
npm start
```

---

## 📦 Ready-to-Deploy Package

If deploying to **cPanel / GoDaddy / Shared Hosting**:
1. Run `npm run package:godaddy` to generate the standalone deployment zip.
2. Upload the generated zip file directly to your hosting file manager.

---

## 🛠 Features

- ⚡ **Real-Time Articles & Categories**: Auto-updated from live cloud DB.
- 📱 **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.
- 🔐 **Secure Admin Portal**: Manage news, media, categories, and breaking alerts.
- 🔴 **Breaking News Ticker & Notifications**: Real-time broadcast alerts.
- 📊 **Dynamic District & State Filtering**: Instant news filtering.
